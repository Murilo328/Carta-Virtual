# Carta Virtual

Projeto simples de carta eletrônica feito com HTML, CSS e JavaScript.

## Como testar
1. Extraia os arquivos do ZIP.
2. Abra o arquivo `index.html` no navegador.
3. O cronômetro libera o botão para abrir a carta à meia-noite de Dublin em 26/10/2026.

## Importante
O bloqueio é feito no navegador com JavaScript, adequado para uma surpresa simples, mas não é uma proteção de segurança: uma pessoa que souber inspecionar o código-fonte poderá encontrar a mensagem antes da data.
